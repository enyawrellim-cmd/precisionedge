01

개요

PrecisionEdge("당사", "저희" 또는 "우리")는 하와이주 유한책임회사인 PrecisionEdge Golf LLC가 개발한 골프 샷 추적 애플리케이션입니다. 당사는 이용자의 개인정보를 보호하고, 데이터를 처리하는 방식에 있어 투명성을 유지하기 위해 최선을 다하고 있습니다.

핵심 요약: 이용자의 샷 데이터는 본인의 기기에만 저장됩니다. 당사는 개인정보를 수집하지 않으며, 이용자를 추적하지 않고, 어떠한 데이터도 제3자에게 판매하지 않습니다.

02

수집하는 데이터

PrecisionEdge는 핵심 기능, 즉 골프 샷 추적과 분산 패턴 분석을 제공하기 위한 목적으로만 다음과 같은 데이터를 수집합니다:

📍

위치 데이터

샷의 출발 지점과 낙하 지점의 GPS 좌표로, 캐리 거리와 좌우 편차를 계산하는 데 사용됩니다.

🎥

카메라 및 AR 데이터

AR 오버레이와 샷 시각화를 위한 카메라 접근 권한입니다. 이미지는 기기 내에서 처리되며 외부로 전송되거나 저장되지 않습니다.

⛳

샷 데이터

클럽 선택, 목표 거리, 캐리 거리, 좌우 편차, 방향각 정보입니다. 모두 이용자의 기기에만 저장됩니다.

🌐

코스 데이터

이용 가능한 경우, 거리 자동 입력을 돕기 위해 제3자 골프 코스 API를 통해 대략적인 코스 및 홀 정보를 가져옵니다.

당사가 수집하지 않는 정보는 다음과 같습니다:

  • 이름, 이메일 주소, 연락처 정보
  • 기기 식별자 또는 광고 ID
  • HealthKit의 건강 또는 피트니스 데이터
  • 웹 검색 기록, 연락처, 사진
  • 분석, 광고, 추적 목적의 일체의 데이터
03

데이터 이용 방식

PrecisionEdge가 수집하는 모든 데이터는 다음과 같은 목적으로만 사용됩니다:

  • 샷 거리 및 분산 패턴의 계산과 표시
  • 샷 궤적의 AR 시각화 렌더링
  • 플레이 중인 골프장의 자동 인식(GPS 및 코스 API 활용)
  • 홀 정보를 기반으로 한 거리 추천 제공

당사는 이용자의 데이터를 광고, 마케팅, 프로파일링, 또는 앱의 핵심 기능과 무관한 어떠한 목적으로도 사용하지 않습니다.

04

데이터 보관 및 보존

모든 샷 데이터는 이용자의 기기 내 저장소에 로컬로 저장됩니다. 어떠한 샷 데이터도 당사 서버나 제3자 서버로 전송되지 않습니다.

이용자의 데이터는 앱 내 데이터 관리 기능을 통해 직접 삭제하기 전까지 기기에 보관됩니다. 앱을 삭제하시면 로컬에 저장된 모든 데이터가 함께 제거됩니다.

당사는 이용자의 개인 데이터를 저장하는 서버를 운영하지 않습니다. 사용자 계정, 클라우드 동기화, 당사 시스템 내 데이터 백업이 일체 존재하지 않습니다.

05

제3자 서비스

PrecisionEdge는 다음과 같은 제3자 서비스를 이용합니다:

  • 골프 코스 API (GolfAPI.io) — 인근 골프장을 식별하고 홀 및 거리 정보를 가져오는 데 사용됩니다. 코스 식별 목적으로만 이용자의 대략적인 GPS 위치가 해당 서비스에 전송되며, 개인정보는 일체 전달되지 않습니다. GolfAPI.io의 개인정보 처리 관행은 자체 개인정보 처리방침의 적용을 받습니다.

당사는 어떠한 제3자 분석 도구, 광고 네트워크, 충돌 보고 도구, 소셜 미디어 SDK도 통합하지 않습니다.

당사는 마케팅 또는 광고 목적으로 이용자의 데이터를 제3자와 공유, 판매, 임대 또는 거래하지 않습니다.

06

이용자의 권리

이용자의 데이터는 전적으로 본인의 기기에 저장되므로, 언제든지 데이터에 대한 완전한 통제권을 가집니다:

  • 열람: 앱 내에서 언제든지 모든 샷 데이터를 확인할 수 있습니다
  • 삭제: 앱 내 관리 도구를 통해 개별 샷, 특정 클럽의 모든 샷, 또는 전체 데이터를 삭제할 수 있습니다
  • 권한 철회: 기기의 설정 앱에서 언제든지 위치 또는 카메라 접근 권한을 비활성화할 수 있습니다
  • 앱 삭제: 앱을 삭제하면 기기에 저장된 모든 관련 데이터가 함께 제거됩니다

데이터에 관한 문의가 있거나 개인정보 관련 권리를 행사하시려면 아래 연락처로 문의해 주시기 바랍니다.

07

아동의 개인정보

PrecisionEdge는 13세 미만 아동을 대상으로 하지 않습니다. 당사는 아동의 개인정보를 고의로 수집하지 않습니다. 본 앱은 어떠한 이용자로부터도 개인정보를 수집하지 않으므로, 아동 데이터에 대한 별도의 특별 조항은 필요하지 않습니다.

08

본 방침의 변경

당사는 본 개인정보 처리방침을 수시로 업데이트할 수 있습니다. 변경 사항은 시행일과 함께 본 페이지에 게시됩니다. 본 방침을 주기적으로 검토해 주시기 바랍니다. 변경 후에도 PrecisionEdge를 계속 이용하시는 경우, 개정된 방침에 동의하신 것으로 간주됩니다.
